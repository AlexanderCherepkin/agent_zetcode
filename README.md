# 🚀 Site Clone Agent (Awwwards 2026 Edition)

Автономная мультимодальная система для клонирования сложных современных сайтов уровня **Awwwards**, извлечения скролл-хореографии, полной локализации всех ассетов (включая обязательное скачивание видео), быстрой подмены контента через единый `content.json` и реконструкции в чистом стеке **Next.js + Tailwind CSS + GSAP**.

---

## 🧠 Ключевые возможности системы

### 1. Умный экстрактор (`playwright-scraper.js`)

- Автоматический фоллбэк браузерных движков **Chromium → Firefox**.
- Автоматическое закрытие всплывающих окон и диалогов:
  - Cookie / GDPR.
  - Политики конфиденциальности.
  - Entry Gates («Enter Site»).
- Ожидание полной загрузки шрифтов, изображений и видеороликов, а также исчезновения прелоадеров.
- **Многовекторный скролл:** вниз, влево, вправо и взаимодействие мышью.
- Математическое распознавание следующих типов эффектов:
  - `trueParallaxElements`.
  - `mouseParallaxElements`.
  - `horizontalScrollContainers`.
  - `stackingOverlappingCards`.
  - `scrollScrubbedVideos`.
- Перехват шейдеров **WebGL (GLSL)** и **WebGPU (WGSL)** во время выполнения, а также **CSS Scroll-Driven Animations** через `animation-timeline`.
- Защита побуквенной анимации **GSAP SplitText / SplitType** при замене заголовков.

### 2. Полная локализация ассетов и видео (`Asset Localizer`)

- **Обязательное скачивание и локальное сохранение всех медиаресурсов:**
  - **Видео (всегда скачиваются локально):** `.mp4`, `.webm`, `.ogg`, `.mov` → сохраняются в `output/site_clone/assets/media/` и привязываются к ключам `vid_1`, `vid_2`... в `content.json` для мгновенной ручной замены.
  - **Изображения и фоны:** `.webp`, `.avif`, `.png`, `.jpg`, `.svg` → сохраняются в `output/site_clone/assets/images/`.
  - **Шрифты:** `.woff2`, `.woff`, `.ttf`, `.otf` → сохраняются в `output/site_clone/assets/fonts/`.
- Обход ограничений анти-хотлинкинга с использованием HTTP-заголовков `Referer` и `Origin`.
- Переписывание всех ссылок в HTML и `url(...)` внутри CSS на локальные пути.

### 3. Визуальный редактор и синхронизатор HTML (`src/index.js`)

- Локальный сервер предпросмотра: [http://localhost:3000](http://localhost:3000).
- **Прямое запекание в `index.html` (`Direct HTML Baker`):** любые изменения, внесённые вручную в `content.json` или через браузер, автоматически вшиваются напрямую в файл `output/site_clone/index.html` и не сбрасываются при обновлении страницы (`F5`).
- Режим **Click-to-Edit**:
  - Клик по любому тексту, изображению, фону или видео непосредственно в браузере.
  - Мгновенное обновление `content.json` и `index.html` на диске.

### 4. ИИ-трансформатор контента (`content-rebrander.js`)

- Автоматический рерайт текстов из `content.json` под новую тематику.
- Использование словаря принудительных замен из `rebrand-config.json`.
- Подключение локальной LLM через `llama-server.exe`.
- Контроль длины строк (**Character Length Guard**) для предотвращения нарушения сетки, компоновки и анимаций.

### 5. Генераторы кода Next.js и продакшен-сборщик (`code-synthesizer.js`, `llm-builder.js`, `static-builder.js`)

- Создание чистого проекта на базе **Next.js (App Router) + Tailwind CSS + GSAP** с переносом параллакс-эффектов и шейдеров.
- Поблочная конвертация секций сайта с помощью локальной Vision-модели (сжатие токенов, посекционные скриншоты).
- Экспорт готового статического сайта в `output/dist/` (`npm run build:static`) с очисткой всех служебных атрибутов `data-agent-*`.

### 6. Страж и Машина времени (`agent-guardian.js`)

- Сохранение неприкосновенного эталона **Golden Master** сразу после скачивания сайта и видео.
- Пошаговая запись всех действий агента: `step_001`, `step_002` и т. д.
- Защита системных JavaScript-движков от перезаписи (**Firewall**).
- Браузерное тестирование (**Smoke Test**) через команду `verify`.
- **ВНИМАНИЕ:** Авто-откат отключен для защиты ваших ручных правок. При поломке кода или белом экране Страж выдаст предупреждение, а откат выполняется по вашему требованию (`npm run rollback`).

## 📂 Архитектура проекта

```text
site-clone-agent/
├── .clinerules                         # Правила безопасности для ИИ-агента в VS Code
├── rebrand-config.json                 # Тематика, настройки бренда и словарь замен
├── package.json                        # Команды управления пайплайном
├── .guardian/                          # Хранилище Стража и Машина времени
│   ├── golden_master/                  # Эталонная копия сайта после парсинга
│   ├── snapshots/                      # Пошаговые снимки: step_001, step_002...
│   ├── history.json                    # Журнал действий агента
│   └── LAST_AGENT_ERROR.log            # Диагноз последней отклонённой правки
├── output/
│   ├── site_clone/                     # Автономный клон сайта с работающими эффектами
│   │   ├── index.html                  # Чистый HTML с синхронизированным контентом
│   │   ├── content.json                # Единый JSON всех текстов, картинок, видео и фонов
│   │   ├── reference.png               # Полноразмерный скриншот исходного сайта
│   │   ├── assets/                     # Локальные шрифты (fonts/), картинки (images/) и ВИДЕО (media/)
│   │   ├── css/                        # Таблицы стилей с локальными путями
│   │   ├── js/                         # Скрипты и мост
│   │   └── specs/                      # Спецификации анимаций, стилей и фреймворков
│   ├── dist/                           # Чистая продакшен-сборка для выгрузки на хостинг
│   └── generated_nextjs_project/       # Сгенерированный проект Next.js + Tailwind + GSAP
│       ├── app/                        # layout.jsx, page.jsx, globals.css
│       ├── components/                 # ScrollEffectsHandler.jsx и секции Section_XX.jsx
│       ├── data/                       # content.json и scroll-choreography.json
│       ├── public/assets/              # Локальные шрифты, изображения и видео
│       └── shaders/                    # Перехваченные шейдеры .glsl и .wgsl
└── src/
    ├── index.js                        # Локальный сервер, авто-синхронизатор HTML и Click-to-Edit
    ├── orchestrator/
    │   └── agent-cli.js                # Интеллектуальный CLI-диспетчер и пре-сканер сайта
    ├── extractor/
    │   └── playwright-scraper.js       # Парсер сайтов, эффектов, параллакса и всех видео/ассетов
    ├── generator/
    │   ├── code-synthesizer.js         # Синтезатор проекта Next.js + GSAP
    │   └── llm-builder.js              # Мультимодальный генератор секций через llama-server
    └── utils/
        ├── agent-guardian.js           # Валидация, браузерный аудит и система откатов
        ├── content-rebrander.js        # ИИ-рерайт и словарь ребрендинга content.json
        └── static-builder.js           # Финальная сборка чистого статического сайта в output/dist/

```
